Dasar Referensi Klinis

Susunan kategori (S-P-O-K) dan metode pada aplikasi ini tidak dibuat sembarangan, melainkan diadaptasi dari literatur kredibel:

  • Picture Exchange Communication System (PECS)
    Oleh Bondy & Frost (2001). Digunakan untuk melatih inisiatif komunikasi non-verbal berfokus pada "Manding" (meminta).
  • Applied Behavior Analysis (ABA) - Verbal Behavior
    Pendekatan B.F. Skinner. Pengelompokan kata ditekankan pada penguat (reinforcer) terlebih dahulu sebelum konsep abstrak.
  • Pendekatan Neurodevelopmental
    Memperhatikan kesiapan perkembangan otak anak dalam memproses bahasa, sejalan dengan prinsip Dr. dr. Purboyo Solek, Sp.A(K), Subsp.Neuro(K).
  • Fitzgerald Key (Warna)
    Penggunaan warna latar kartu (Kuning untuk Subjek, Hijau untuk Kata Kerja, dsb) mengacu pada standar visual internasional untuk AAC.

Tentang Aplikasi

Aplikasi ini dikembangkan secara mandiri dengan tujuan mulia untuk memfasilitasi anak-anak berkebutuhan khusus (ASD, Disabilitas Intelektual, dll) agar memiliki suara.

Aplikasi ini disediakan 100% Gratis tanpa iklan.
